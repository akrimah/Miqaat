# Miqaat Mobile App (Future)

Native iOS and Android apps will live here, built with **Flutter**.

They will consume the same REST API as the web app:

- `GET /api/methods`
- `POST /api/prayer-times`
- `POST /api/export/ics`

Do not duplicate prayer-time calculation logic in the mobile client.

See [`docs/API.md`](../docs/API.md) when available.
